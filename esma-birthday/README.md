# Esma birthday

## How to preview (easiest)

1. Put your 6 photos into this folder (`C:\Users\Adam Vlček\esma-birthday`):
   - `obrazek_1.jpg`
   - `obrazek_2.jpg`
   - `obrazek_3.png`
   - `obrazek_4.PNG`
   - `obrazek_5.JPEG`
   - `obrazek_6.jpg`
2. Double-click `index.html` — it opens in your browser.
3. Or right-click `index.html` → Open with → Chrome / Edge.

Names must match exactly (including `.PNG` / `.JPEG` capital letters).

## Edit texts

Replace every `x` in:
- `index.html`
- top of `script.js` (`CONFIG`)
